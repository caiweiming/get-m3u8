帮助

这里汇总常用下载流程和任务操作。所有下载都在本地浏览器中完成，遇到源站跨域或鉴权限制时，可能需要更换链接或重新获取有效地址。

快速开始

  1. 点击“新建下载”，粘贴 m3u8 地址。
  2. 按需填写保存标题、保存格式、下载范围和并发数。
  3. 点击“开始下载”，如存在多个清晰度，先选择分辨率。
  4. 如果源提供多轨媒体，可选择可用的外部音轨和 WebVTT 字幕。
  5. 下载完成后，浏览器会保存对应的视频文件。

任务操作

  • 下载按钮用于开始或重新下载可恢复任务。
  • 暂停会中止当前网络请求，再次点击可继续未完成分片。
  • 播放可打开预览窗口，删除会先弹出确认。
  • 勾选任务后，可使用顶部批量开始、暂停、删除。

高级能力

  • 范围下载会在解析出真实分片后确认起止片号。
  • 边下边存可降低内存占用，但不支持强制合并。
  • 本地缓存用于刷新后恢复已下载分片，可在任务列表上方管理。
  • 独立音轨、字幕会分别保存为独立文件；直接打开视频可能无声，需要手动加载音轨或合并后播放。
  • 点击任务进度条可查看分片状态，失败分片可点击重试。

快捷下载 URL 参数

  • source：m3u8 地址，推荐 URL 编码。
  • title：预填保存标题。
  • format：ts 或 mp4。
  • streamSave：1/true 开启边下边存。
  • range：all 或 custom。
  • concurrency：分片并发数，范围 1-8。
  • _ignore：从 source 内部移除指定参数。
示例： https://getm3u8.com?source=https%3A%2F%2Fexample.com%2Fvideo.m3u8&title=demo&format=mp4
